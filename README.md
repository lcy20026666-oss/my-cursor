# My Cursor：桌面智能体课程作业

## 1. 项目简介

My Cursor 是一个基于 Python、PySide6 和 DeepSeek 模型接口开发的桌面智能体课程项目，旨在实现一个具备模型对话能力、本地文件操作能力和受限工具调用能力的桌面应用。

项目采用图形化交互界面，将大语言模型与本地工具相结合，提供文件读取、文件修改、命令执行、自动化测试和只读智能体工具调用等功能。

## 2. 主要功能

### 2.1 桌面交互界面

- 文件选择与读取
- 文件内容编辑与保存
- 受限本地命令执行
- 项目测试运行
- DeepSeek 模型对话
- 工具执行日志展示

### 2.2 DeepSeek 模型接入

通过 OpenAI 兼容接口调用 DeepSeek 模型，实现自然语言对话。模型配置通过环境变量读取，包括 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL` 和 `DEEPSEEK_MODEL`。

### 2.3 本地工具

| 工具 | 功能 |
|---|---|
| `read_file` | 读取授权工作区内的文本文件 |
| `search_project` | 在授权工作区内搜索代码关键词 |
| `edit_file` | 按程序规则修改文件并生成差异信息 |
| `run_command` | 执行白名单范围内的本地命令 |
| `run_tests` | 运行项目自动化测试 |

### 2.4 只读智能体工具调用

当前智能体自动调用范围限定为 `read_file` 和 `search_project`。智能体会校验工具参数、限制文件访问范围，并限制每轮工具调用次数。

智能体不会自动修改文件、执行本地命令或运行测试。文件编辑、命令执行和测试运行仍需通过桌面界面中的独立操作入口完成。

## 3. 安全机制

1. **工作区路径限制**：校验目标路径，避免访问授权工作区以外的文件。
2. **命令白名单**：仅允许配置范围内的命令。
3. **操作确认**：对文件保存和命令执行等操作设置确认机制。
4. **工具参数校验**：检查智能体传入的工具名称和参数。
5. **调用次数限制**：限制单轮自动工具调用次数，降低异常循环风险。
6. **密钥保护**：通过 `.env` 保存 API Key，并使用 `.gitignore` 排除敏感配置。

## 4. 环境要求

- 操作系统：Windows
- Python：3.14.6（项目开发环境）
- 桌面界面：PySide6
- 模型接口：DeepSeek OpenAI 兼容接口

## 5. 安装依赖

在项目根目录运行：

```bash
python -m pip install -r requirements.txt
```

## 6. 配置 DeepSeek 模型

1. 将 `.env.example` 复制一份，并命名为 `.env`。
2. 在 `.env` 文件中填写自己的模型配置：

```dotenv
DEEPSEEK_API_KEY=填写自己的API密钥
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-flash
```

3. 保存配置后启动程序。

**安全提示：不要将 `.env`、API Key 或其他个人凭据上传到 GitHub。** 公开仓库中只保留不含真实密钥的 `.env.example`。

## 7. 启动桌面应用

```bash
python app.py
```

## 8. 运行自动化测试

```bash
python -m unittest discover -s tests -v
```

测试内容包括文件路径安全校验、工具参数校验、文件读取与搜索功能、工具调用次数限制、异常输入处理和智能体工具调用边界。

此前一次完整测试记录为 51 项测试通过。正式发布前应重新运行测试，并以实际运行结果作为最终测试记录。

## 9. MCP 实现状态

项目包含 `mcp_client.py` 模块，目前该模块仍为状态占位实现，尚未连接真实 MCP Server。

因此，当前版本不宣称已经实现真实 MCP Server 的工具发现、协议通信或远程工具调用。后续可在此基础上扩展 MCP 客户端与服务端集成。
